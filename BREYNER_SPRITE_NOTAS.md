# Breyner — primera integración de sprite

- `assets/characters/breyner/overworld.png` es la hoja integrada para la prueba inicial.
- Tamaño de hoja: 192 × 256 px; cada celda mide 48 × 64 px.
- Orden de filas: abajo/frente, izquierda, derecha, arriba/espalda.
- Se conserva la hoja anterior en `assets/characters/breyner/overworld.png.backup-before-redesign`.
- La hoja nueva se preparó recortando la referencia visual aprobada. Es un primer atlas de integración; las variaciones de los fotogramas aún son sutiles y requieren una revisión dentro de Pygame.
- No se modificaron los sprites de Cristel ni de su madre.
- La compilación de Python no equivale a una prueba visual del juego.
