# Lista de comprobación antes de publicar Olvido

- [ ] Instalar dependencias con `python -m pip install -r requirements.txt`.
- [ ] (Opcional) Ejecutar los scripts de `_fuera_del_juego/tools/` desde la carpeta del juego; ya no van dentro de ella para no inflar el build web.
- [ ] Ejecutar `python -m compileall -q .`.
- [ ] Iniciar con `python main.py` y comprobar menú, diálogos y movimiento.
- [ ] Probar cada escena, los minijuegos, el inventario y el guardado/carga.
- [ ] Revisar visualmente las cuatro direcciones de cada personaje.
- [ ] Confirmar los derechos de publicación de imágenes, audio y textos.
- [ ] Confirmar que no se incluyen partidas guardadas, claves ni datos personales.
- [ ] Añadir una licencia solo cuando se haya decidido qué permisos de reutilización conceder.

La validación automática no significa que todos los elementos hayan sido probados en ejecución.
